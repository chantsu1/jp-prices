# 東証株価の自動取得（テーマ予兆・予兆チェック用）

平日の夕方に、`tickers.csv` の銘柄の終値を Yahoo Finance から取得し、
`data/metrics.csv`（上昇率・52週高値からの距離・移動平均など）と `data/prices.csv`（終値の履歴）を更新します。
Claude の定期タスクがこのファイルを読んで、テーマ予兆の判定に使います。

- 銘柄の追加・削除は `tickers.csv` を編集するだけです（コードは4桁、指数は ^N225 のように書く）。
- Yahoo Finance の非公式な取得方法（yfinance）を使っているため、仕様変更で止まることがあります。
  その場合は Actions の画面に赤い印が付きます。
- 個人の参考用です。投資判断は自己責任で。
